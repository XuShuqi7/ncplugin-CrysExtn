# The CrysText plugin for NCrystal

This repository contains code for the NCrystal plugin named `CrysText`.

This plugin is developed based on the March-Dollase texture model. A detailed description of the implemented model is found: V. Santoro et al. (DOI 10.3233/JNR-230950) pages 249-251. A known issue affecting calculations at lower wavelengths has been reported at https://github.com/mctools/ncrystal/issues/215.
